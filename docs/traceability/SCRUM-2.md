## Deviations from the design

| Design reference | Deviation | Reason |
|---|---|---|
| §2 / §3 / §5: `TaskController` annotated `@Validated` | Controller is **not** annotated `@Validated`; `@Min` on `page`/`size` is enforced by Spring MVC 7 built-in method validation. | In Spring Framework 7 (`HandlerMethod.MethodValidationInitializer#checkArguments`) a class-level `@Validated` disables built-in method validation and the AOP `MethodValidationPostProcessor` would throw `ConstraintViolationException` (→ 500 via the catch-all) instead of `HandlerMethodValidationException` (→ 400, A-07). |
| §12: git-commit-id execution id `get-the-git-infos` | Execution id is `default`. | Merges with the `revision` execution inherited from `spring-boot-starter-parent` so the goal runs once instead of twice. Phase/goal/configuration as designed. |
| §10: CI trigger `push: branches: ["**"]` | `push` on `feature/**` and `main`, plus `pull_request`. | Developer task instruction. |
| §9 `TaskControllerTest` AC-12: "verify via `ArgumentCaptor`" | Verified with `ArgumentCaptor`/`verify` that the service receives exactly the expected request record (which has no `id`/`createdAt` components). | Same intent. |
| §6 / §8 / ADR 0003: `server.error.include-stacktrace` / `server.error.include-message` | Set as `spring.web.error.include-stacktrace` / `spring.web.error.include-message`. | Spring Boot 4.0 moved these keys; the `server.error.*` names are deprecated with level `error` (replacement `spring.web.error.*`) in Boot 4.1.2 metadata, so they would not take effect. |
| — | Added `.gitattributes` (LF for `mvnw`, CRLF for `*.cmd`). | Keeps the wrapper scripts runnable across platforms. |
